# キーボード表示サイズ拡大およびDPI最適化 実装計画

## 概要
スマートフォン実機（Xperia SOG10、6.5インチ画面）において、Android Auto 投影時のバーチャルキーボードが極小で操作が困難な問題を解消します。
車載大画面（10〜12インチ）向けの解像度密度（213 DPI）から、スマホ画面に適した **280 DPI** へ最適化することで、映像解像度（1080p）や Coolwalk 2画面分割レイアウト（左：Spotify / 右：Googleマップ）を完全に維持したまま、キーボードおよびUI要素を約 **31% 拡大** し、快適なタッチ操作を実現します。

本修正は新設ブランチ `feature/keyboard-dpi-optimization` にて実施します。

---

## ユーザー確認事項

- **解像度（1920×1080 / 1920×822）およびアスペクト比（21:9）に変更はありません。**
- **Coolwalk 2画面分割構造（地図＋音楽カード＋ドック）はそのまま維持されます。**
  - 280 DPI 時の有効幅は **1097 dp**（分割要件の約 900 dp を余裕をもって上回る値）となります。
- タッチ座標マッピング計算式はピクセル解像度（1920×822）基準であるため、座標のズレは生じません。
- 地図の表示領域（視野角）が約1段階分ズームインされた状態となります（画面上の「＋ / −」ボタンやピンチで自由に縮尺変更可能）。

---

## 変更内容

### [Core Config]

#### [MODIFY] ProjectionDisplayConfig.kt
- `DENSITY_DPI` を `213` から `280` に変更。
  - `ControlChannel.kt` の `videoService` 経由で Android Auto（Gearhead）に報告される DPI が更新され、Gearhead が描画する仮想ディスプレイの DPI が 280 に設定されます。

## 検証手順

### 自動テスト
1. `./gradlew testDebugUnitTest assembleDebug` を実行し、全テスト通過と APK ビルド成功を確認。

### 実機検証
1. `adb install -r app/build/outputs/apk/debug/app-debug.apk` でアプリを更新。
2. アプリを起動し、Google マップまたは Spotify の検索バーをタップしてキーボードを表示。
3. キーボードの各キーが十分に拡大され、指で快適にタップ・入力できることを確認。
4. 2画面分割（Coolwalk）レイアウトが正常に維持されていることを確認。
5. タッチ座標にズレがないことを確認。
